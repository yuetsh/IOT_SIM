#### 3. 数组（PDF 69–73 / 书 66–70）
- (1) 定义：相同类型的元素按顺序排列的集合；有数组名、下标、元素；C# 数组下标从0开始；声明时 `[]` 必须写在类型后面（`int[] table;`，不能写 `int table[]`）；数组大小不属于类型的一部分（`int[] numbers; numbers = new int[10]; numbers = new int[20];`）。
- (2) 声明：一维 `int[] numbers;`、多维 `string[,] names;`、交错 `string[][] scores;`。声明之后必须实例化。
- (3) 创建：`new int[5]`、`new string[5,4]`；交错数组 `byte[][] scores = new byte[5][]; for(...) scores[x] = new byte[4];`；三维 `int[,,] buttons = new int[4,5,3];`；混合写法 `int[][,,][,] numbers;`。
  示例 `Form1_Click`：建交错数组 `scores[i] = new byte[i + 3]`，然后 `MessageBox.Show("Length of row " + i + " is " + scores[i].Length);`。
- (4) 初始化：未初始化时元素取类型默认值，字段数组默认是 null。
  - 一维：`new int[5] {1,2,3,4,5}`、`new int[] {...}`、`int[] numbers = {1,2,3,4,5};`、`string[] names = {"Matt","Joanne","Robert"};`
  - 多维：`new int[3,2] {{1,2},{3,4},{5,6}}`、`string[,] siblings = {{"Mike","Amy"},{"Mary","Albert"}};`
  - 交错：`new int[2][] { new int[] {2,3,4}, new int[] {5,6,7,8,9} }`，可以省略第一维大小，也可以省略 new。交错数组的元素没有初始化语法。
- (5) 访问元素：`numbers[4] = 5;`、`numbers[1, 1] = 5;`、`numbers[0][0] = 100; numbers[1][1] = 200;`
- (6) 数组是对象：基类是 `System.Array`；`int LengthOfNumbers = numbers.Length;`；还有排序、搜索、复制等方法。
- (7) 用 foreach 遍历数组：`int[] numbers = {4,5,6,1,2,3,-2,-1,0}; foreach (int i in numbers) MessageBox.Show(i.ToString());`。多维数组同样可以 foreach，`new int[3,2]{{9,99},{8,88},{7,77}}` 输出 `9 99 8 88 7 77`。多维数组用嵌套 for 能控制得更细。

**知识提炼**：
1. 数据库（database，DB）：长期存储在计算机内、有组织、可共享的数据集合，按一定的数据模型组织、描述和存储，冗余度小、数据独立性高、容易扩展，可以在一定范围内供多个用户共享。
2. 数据库管理系统（DBMS）：用户和操作系统之间的一层数据管理软件（如 SQL 数据库管理系统），用来建立、使用和维护数据库，统一管理和控制数据库，保证安全性和完整性。
3. 数据表：数据库的组成部分，是实际存储数据的地方，每个数据库都有自己的数据表。表由行和列组成，建表就是定义列的过程。
4. 字段与记录：表里的每一行叫一条记录，表示所存物体各方面的属性；每个数据项叫字段，表示物体某方面的性质，比如学生信息里的学号、姓名、出生日期。
5. 主键：能唯一标识表中每一行，可以是一个字段，也可以是多个字段的组合，用来强制实体完整性。一个表只能有一个主键，主键列不能为空。例如学生表（学号、姓名、性别、班级）中学号唯一，就是主键。
6. SQL 数据类型：SQL Server 有 20 多种系统数据类型，插入的值超出允许范围就会报错。常用的有：
   1) bit：只能是0、1或空值
   2) tinyint：0～255，占1B
   3) smallint：-32768～32767，占2字节
   4) int：-2147483648～2147483647，占4B
   5) money：-9220亿～9220亿，精确到货币单位的万分之一
   6) float：-1.79×10^308～1.79×10^308，是近似值
   7) smalldatetime：精确到1min
   8) datetime：精确到1/300s
   9) uniqueidentifier：GUID 全局唯一标识
   10) char：定长、非统一编码，必须指定列长
   11) varchar：变长，必须指定最大长度
   12) text：最多 2^31-1（约20亿）个字符
   13) nvarchar：统一编码、变长，能存4000个字符，占用字节翻倍
   14) ntext：2^30-1（近10亿）个字符，占用字节翻倍
   15) binary：最多8000B的定长二进制
   16) varbinary：最多8000B的变长二进制，内容大小会变时用它
   17) image：变长二进制，最多 2^31-1（约20亿）B

  - ListBox，DataGridView（可编辑，CurrentRow.Cells[0].Value）。
  - GroupBox，Timer（Interval 最大要能到 7200000），以及 Visible、Enabled、ForeColor 的动态切换（用于闪烁效果）。

    - SetData() 返回 ADAM4150ResModel，字段有 infraredValue（DI3）、fireValue（DI1）、smokeValue（DI2）。

  - ipCameraHelper：
    - 方法：`Open(ip, "admin", "")`、`Start()`、`Stop()`、`PanUp/PanDown/PanLeft/PanRight()`。
    - 事件：`ImageRead += handler(ImageReadEvenArgs e)`，用 `e.img` 取图。

  - 串口服务器、路由器的配置只是硬件准备步骤，模拟器里不用体现。

- **线程**：
  - Thread 的 Start、Suspend、Resume、Abort、Sleep，ThreadState。
  - `Control.CheckForIllegalCrossThreadCalls = false`：后台线程直接改 UI 也要能生效。
- **数据库（ADO.NET + T-SQL 子集）**：
  - ADO.NET 对象：SqlConnection(连接串).Open()，SqlCommand.ExecuteNonQuery()，SqlDataAdapter.Fill(DataSet)，`ds.Tables[0].DefaultView` 作为 DataSource，`SqlCommandBuilder.GetUpdateCommand()` 和 `adapter.Update(DataTable)`（返回受影响行数）。
  - SQL 语句：带中文别名的 `select ... as '编号' ...`，不写列名的 `insert into T values (...)`，`delete from T where id=...`。
  - 类型和库名：varchar(MAX)、varchar(50)、varchar(200)、date、datetime、int IDENTITY 主键；中文数据库名"环境数据表"。
  - 连接串：服务器名、sa 密码这些要能宽松接受，不管写的是 `.` 还是 `PC-…\SQLSERVER1026` 都映射到学生自己的沙箱库。
  - 任务1 的 SSMS 操作（新建数据库、新建表、编辑前200行）需要一个简化的网页版"表设计器 + 数据编辑"界面，或者改成让学生写 SQL。
