#### 知识提炼（书124–126）
1. **insert 插入语句**：`insert into 表名 (列1, 列2, ...) values (值1, 值2, ...);`。示例表 user 有 id（自增主键）、username varchar(50)、birthday date 三个字段：
   - 完整插入 `insert into user (id, username, birthday) values (1, '张三', '1999-09-09');`
   - 部分插入 `insert into user (username) values ('李四');`（id 自增）
   - 简写插入 `insert into user values ('王五', '1910-10-10');`（按字段顺序填写，跳过自增 id）
2. **update 更新语句**：`update 表名 set 列1=新值1, 列2=新值2, ... [where 条件];`。示例：`update user set birthday='2016-01-01' where username='张三';`；还有 T-SQL 特有写法 `update top (3) user set birthday='2000-01-01';`
3. **delete 删除语句**：`delete from 表名 [where 条件];`。示例：`delete from user where username='张三';`、`delete top (5) from user;`、`delete from user;`
4. **ADO.NET 对象模型简介**：ADO.NET 由「.NET 数据提供程序」和「数据集 DataSet」两部分组成。表6-2 ADO.NET 核心组件：

| 对象 | 说明 | 特点 |
|---|---|---|
| Connection | 建立与特定数据库的连接 | 可以自己创建，也可由其他对象自动产生（如 DataAdapter） |
| Command | 对数据源执行命令 | 通过 Connection 对象下达命令，Connection 的指向决定操作对象 |
| DataAdapter | 从数据源中检索数据并填充 DataSet 中的表 | DataAdapter 填充到 DataSet 中的是断开连接的脱机数据 |
| DataReader | 从数据库中检索只读的数据流 | DataReader 读取数据必须在维持数据库连接的前提下进行 |
| DataSet | 在内存中缓存从数据源中检索到的数据 | 独立于其他数据源 |

5. **ADO.NET 中的 SQL 操作类**
   - SqlConnection：表示一个打开的 SQL Server 连接，不能被继承；OLE DB 数据源要用 OleDbConnection。有两个构造函数：`SqlConnection()` 和 `SqlConnection(String 连接字符串)`。用完后关闭。
   - SqlCommand：执行 T-SQL 语句或存储过程。有四个构造函数：`()`、`(String)`、`(String, SqlConnection)`、`(String, SqlConnection, SqlTransaction)`。
   - SqlDataReader：从上往下读取只读数据。必须通过 `SqlCommand.ExecuteReader()` 创建，不能直接用构造函数。使用期间连接被它独占，必须调用 `Close()` 后连接才能做其他操作。

**知识提炼**（书128–130）
1. **select 查询语句**：`SELECT 列名称 FROM 表名称` 或 `SELECT * FROM 表名称`。小贴士：SQL 对大小写不敏感。示例：`SELECT * FROM user`、`SELECT id,username FROM user`。表6-4 where 子句运算符：

| 运算符 | 描述 | 实例 |
|---|---|---|
| = | 等于 | 查询表中姓名为张三的生日数据：`SELECT * FROM user where username='张三'` |
| <> | 不等于。在 SQL 的一些版本中可写成 != | 查询表中姓名不是张三的生日数据：`SELECT * FROM user where username<>'张三'` |
| > | 大于 | 查询表中生日为2000年后的数据：`SELECT * FROM user where year(birthday)>2000` |
| < | 小于 | 查询表中生日为2000年前的数据：`... where year(birthday)<2000` |
| >= | 大于等于 | 查询表中生日为2000年（含2000）后的数据：`... where year(birthday)>=2000` |
| <= | 小于等于 | 查询表中生日为2000年（含2000）前的数据：`... where year(birthday)<=2000` |
| between | 在某个范围内 | 查询表中生日为2000—2006年之间的数据：`... where year(birthday) between 2000 in 2006`（书上原文就是 `in`，正确写法应为 `and`） |
| like | 搜索某种模式 | 查询表中姓张的数据：`SELECT * FROM user where username like '张%'` |

   逻辑运算符：AND 要求所有条件都成立，OR 只要一个条件成立即可。
2. **SqlDataAdapter 类**：DataSet 与 SQL Server 之间的桥接器，通过 Fill（让 DataSet 跟数据源一致）和 Update（让数据源跟 DataSet 一致）工作。
3. **DataSet 类**：内存中的临时数据库，包含 DataTable、DataView。第 i 行第 j 列的访问方式是 `ds.Tables[0].Rows[i].ItemArray[j]`，索引从 0 开始。
4. **DataGridView 控件**：表格形式显示和编辑数据；绑定时设置 DataSource，数据源含多个表时再设置 DataMember。
5. **DateTimePicker 控件**：Format 枚举（DateTimePickerFormat）可取 Long / Short / Time / Custom，选 Custom 时用 CustomFormat 字符串；Text 返回文本，Value 返回 DateTime；MinDate / MaxDate 限制范围；点下箭头弹出日历；ShowUpDown 显示上下箭头。三种常用设置：
   - 只显示时间：Format=Time，ShowUpDown=true
   - 只显示时分（如 7:30）：Format=Custom，CustomFormat=`HH:mm`
   - 显示日期和时间：Format=Custom，CustomFormat=`yyyy:MM:dd HH:mm:ss`（书上原文如此）
