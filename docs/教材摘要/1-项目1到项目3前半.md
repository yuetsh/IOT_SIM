**知识提炼**（书 p7–12）
1. **类**：类是创建对象的模板。用 `类修饰符 class 类名 { }` 声明，例如 `public class People { string name; int age; }`。静态类只能通过类名访问。继承写成 `class classChild : newClassName`。小贴士：继承时子类和基类之间必须用冒号。
2. **对象**：用 `new 类名()` 创建。示例 `Student` 类有字段 name、无参构造函数（name="unknown"）、带参构造函数和 `SetName` 方法；最后用 `MessageBox.Show(student1.name + " " + student2.name)` 输出。
3. **命名空间**：用 `using 命名空间名称;` 引入。示例 `namespace TestN { class A { PrintMsg() → MessageBox.Show("物联网编程与应用") } }`，在 Form1_Load 中 `new A().PrintMsg()`。
4. **注释**：单行用 `//`，多行用 `/* */`。示例是控制台程序，用到 `Console.WriteLine` 和 `Console.ReadLine`。
5. **属性**：用 get/set 控制对私有字段的读写，至少要有其中一个。示例 Student 类：`School` 只读（默认值 "浙江**职业中学"），`Name` 只写，`Age` 可读写；`Display()` 用 Console.WriteLine 输出；Main 中用 `Console.Write("学校："+stu1.School)`。
6. **this 关键字**：this 代表当前实例，静态方法中不能用。示例 `this.Age = age; this.Name = name;`。

4. **Dictionary 类**：按键查找值，键必须唯一。格式 `Dictionary<key,value> DemoDic = new Dictionary<key,value>();`。示例用到 Add、按索引器取值 `Dic[2]`、ContainsKey(3)、Remove(2)、ContainsValue("张三")。

### 项目2：书与参考工程的差异，以及模拟器要注意的点
- **串口列表的填充时机不同**：书中任务1 在 `com_Port_Click` 里填，任务2、3 在窗体 `Load` 里填；参考工程三个任务都在下拉框的 **Click** 事件里填（任务1 的 handler 名是 `com_port_Click`，绑定到 `com_Port.Click`）。**模拟器的 ComboBox 必须支持 Click 事件**，要在点击、展开之前触发，这样 Items 才能在展开前更新。`SerialPort.GetPortNames()` 需要返回虚拟串口列表，例如 COM1–COMn。
- **IsOpen 写法不同**：书中是 `bool IsOpen=false` 加 `if(!IsOpen){...IsOpen=True}`；参考工程是 `bool IsOpen = true`，先 `IsOpen = !IsOpen` 再判断，事件内容都包在 try/catch 中。书上写成了 `True/False`（首字母大写），C# 编译会报错，模拟器的编译错误提示要能指出这一点。
- **控件名差异**：
  - 任务2、3 参考工程的窗体名都是 Form1（书为 frm_analog / frm_LED）。
  - 组合框名是 groupBox1/2（书为 grp_show / grp_config），标签是 label1–5（书为 lbl_*）。
  - 任务3 的按钮在书上和参考工程里都叫 **`btn_open`**（小写 o），但表2-15 写的是 btn_Open。
  - LED 自定义控件实例名为 **`led`**（类型 `WinFormsDeviceControlLibrary.LED`），表2-1 写的是“LED”。
- **`DeviceCtrlHelper.ledHelper.Close()`**：书中任务3 第10步调用了它，但参考工程没有调用，《设备控制类库使用说明》中 LED 部分也只列了 `OpenLedCom(string)` 和 `SendLedString(string)`，仿真 dll 很可能没有这个方法。模拟器可以二选一：提供一个空实现以兼容书上的代码，或者给出明确的编译错误。建议提供空实现。
- **SendLedString 的约定**：成功时返回传入的字符串，失败时返回 `"Error:发送失败"`（见使用说明）。LED 控件 `setLedText(string)` 负责显示，控件内部还有 `LedTimer`，推测会滚动显示。
- **工具箱里的 4 个自定义控件**：Alarm、Lamp、LED、ShowMsg（图2-5）。ShowMsg 在本范围内没有出现，从 dll 符号看它包含 txt_showMsg、btn_red、btn_green、btn_Clear 和 AddText，后续项目可能用到。
- 任务2 能力拓展需要 **Timer**（Interval、Enabled、Start/Stop、Tick）和图片显示（Label.Image 或 PictureBox，以及 Visible）。
- 任务3 知识提炼需要 `Font` 构造函数和中文字体，还需要 `UseSystemPasswordChar`、`\t` 制表符的显示，以及多行 TextBox。
- 知识提炼中的 SerialPort 直接收发示例（Base64 + Unicode）超出了“学生不学协议”的范围，可以只作阅读材料。如果要能运行，需要模拟 `new SerialPort()`、Open、WriteLine、ReadLine 和 Close。

### 项目3（到书 p62 为止）：书与参考工程的差异，以及模拟器要注意的点
- **任务1 控件不同**：书中用单选按钮 `rb_Open/rb_Close` 和 CheckedChanged 开关灯；参考工程 `项目3/任务一/ZigBee路灯` 用的是**按钮** `btn_lampOpen/btn_lampClose` 和 Click，与任务2 一样。参考工程没有 rb_*，groupBox 名为 `groupbox1`（小写 b），标签 `label1` 的 Text 为“路    灯”。另外书中表3-1 写 `btn_Open`，代码写 `btn_open`，参考工程也是 `btn_open`。
- 用单选按钮做开关时要注意：CheckedChanged 在选中和取消选中时**都会**触发。rb_Open 被取消（因为选了 rb_Close）时，如果只写 `LampOnOff(1,true)` 就会出问题。书上的写法只在“两个 handler 各自绑定、不判断 Checked”的情况下“恰好能用”：选“关”时两个事件都会触发，先触发谁决定最终状态。**模拟器必须按真实 WinForms 顺序触发 CheckedChanged**：先是被取消的那个，再是被选中的那个。这样书上的代码会在“开灯”和“关灯”各执行一次后停在正确状态。
- 参考工程中串口列表在 `com_lamp_Click` / `com_environment_Click`（ComboBox 的 Click）中填充，书中则在 Form1_Load 中填充。参考工程的所有 handler 都包了 try/catch。
- 参考工程的 timer1 是 Interval=5000，Enabled 为默认 false，与表3-3 一致。
- `zigBeeHelper.OnOff(RelayNum, IsOpen)`：使用说明写继电器通道为 0~1，书和参考工程都用 1。`zigBeeHelper.Close()` 在使用说明里误拼为 `Colse()`，仿真 dll 里实际是 `Close`。
- `adam4150Helper.SetData()` 返回 `ADAM4150ResModel`，包含 bool 型的 bodyInfraredValue、fireValue、smokeValue、infraredValue。`adam4150Helper.Open(string PortName, int BodyInfrared_Port=0, int Fire_Port=1, int Smoke_Port=2, int Infrared_Port=3)`；另有 `adam4150Helper.OnOff(int DO, bool IsOpen)`（DO 0~4）。**模拟器要提供“人体红外”的虚拟触发开关，学生用它模拟有人经过。**
- `Lamp` 控件的方法是 `lamp1.OnOff(bool)`，图片资源在 `开发文档/图片资源/控件图片/LampOn.png` 和 `LampOff.png`。
- 复选框用的是 **Click** 事件而不是 CheckedChanged。Click 触发时 Checked 已经切换过了，模拟器要保证这个时序。
- 任务1 能力拓展用到 `DateTime.Now.Hour`；自主探究“根据大气压控制路灯”要用 adam4017 的 airPressureValue（string 类型，要 Parse），所以需要同时打开 ADAM4017 和 ZigBee 两个虚拟串口。
